## 🚀 Featured Projects

### 🧬 [p53 Protein Functional Characterization](https://github.com/riyajain-sudo/mini_bioinfo_project)

An in-silico bioinformatics project focused on the human p53 protein (TP53) using sequence analysis and homology-based annotation.

- Protein sequence retrieval, validation, and quality analysis
- Homology searching with BLAST
- Functional annotation using UniProt
- Biological interpretation of sequence-based findings

**Focus:** Bioinformatics · Python · BLAST · UniProt · Computational Biology

### 🧪 [DNA Nucleotide Count Web App](https://github.com/riyajain-sudo/nucleotide_count_web_app)

A Python web application that analyzes a DNA sequence and calculates the counts of its four nucleotide bases.

- Counts adenine (A), thymine (T), guanine (G), and cytosine (C)
- Presents results as text and a structured data table
- Visualizes nucleotide composition with a bar chart

**Focus:** Python · Streamlit · Pandas · Altair · DNA Sequence Analysis

### 🌍 [Tourism — MERN Application](https://github.com/riyajain-sudo/MERN_app)

A full-stack application that lets users share places, upload images, and explore locations on a map.

- User registration and authentication
- Create, view, update, and delete place listings
- Image uploads and map-based location display
- REST API integration with MongoDB

**Focus:** React · Node.js · Express.js · MongoDB · REST APIs

### ✍️ [The Comment Section](https://github.com/riyajain-sudo/thecommentsection)

A poetry and thought-sharing platform where people can publish their writing under their username or anonymously.

- Create and browse poems and short thoughts
- Authentication with JWT-based sessions
- Like, favorite, search, and filter posts
- Responsive interface with a soft pastel visual style

**Focus:** MERN Stack · React · Express.js · MongoDB · JWT · UI Development
